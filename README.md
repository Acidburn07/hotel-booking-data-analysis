# Hotel Booking Data Analysis

Final group project for **Data Processing with Python** (HAMK, CA25 Customer Projects).

We analyse 1,000 hotel bookings from a city hotel in Lisbon and a resort hotel in the Algarve (arrivals July 2015 to August 2017), looking at cancellations, booking patterns, prices and differences between the two hotels.

## How to run

Install pandas, numpy, matplotlib and jupyter (`pip install -r requirements.txt`), then open `notebooks/Hotel_Booking_Final_Project.ipynb` and run all cells.

Data source: António, N., de Almeida, A., & Nunes, L. (2019). Hotel booking demand datasets. *Data in Brief*, 22, 41–49. https://doi.org/10.1016/j.dib.2018.11.126
